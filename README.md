# Traitement automatique de l'oral - Occitan
Ce projet est mené dans le cadre de mon stage de fin de Master TAL, au sein du projet TARTOAS. L'objectif de ce projet est la conception d'un modèle de transcription de l'occitan oral vers l'alphabet phonétique international. Nous commençons par tester un modèle déjà existant: wav2vec2phoneme.
